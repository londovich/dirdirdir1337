# Директор чата

Развлекательный Discord-бот для сервера `1541744004188868689` и канала `1541744004708966442`.

## Возможности

- анонимно сохраняет разрешённые текстовые сообщения в SQLite;
- игнорирует ссылки, упоминания, команды, ботов и системные сообщения;
- отвечает на упоминание и с заданной вероятностью в целевом канале;
- генерирует фразы цепью Маркова;
- создаёт демотиваторы через Pillow;
- публикует контекстные опросы раз в 6 часов;
- `/chance` доступна только администраторам.

Бот не сохраняет ID или имя автора. Вложения сохраняются только как URL для будущего расширения библиотеки шаблонов.

## Запуск локально

1. Создайте приложение и бота в Discord Developer Portal.
2. Включите **Message Content Intent** и выдайте боту права `View Channel`, `Send Messages`, `Read Message History`, `Attach Files` и `Use Slash Commands`.
3. Скопируйте `.env.example` в `.env` и вставьте новый токен.
4. Установите зависимости и запустите:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python bot.py
```

После старта команды синхронизируются только с указанным сервером.

## VPS / Docker

```bash
cp .env.example .env
nano .env
docker compose up -d --build
docker compose logs -f
```

Токены и секреты нельзя помещать в git. Переданный в чат токен необходимо отозвать в Developer Portal и выпустить новый.
